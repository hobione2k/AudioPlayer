# 仕様

## 動作環境

ブラウザ上でローカル動作

## 機能

### オーディオファイルの再生

* オーディオファイルの再生機能を備える

#### 対応ファイル

* wav/mp3/ogg/flac/m4a

### 再生リスト

* 複数オーディオファイルをドラッグアンドドロップすると再生リストに追加される
* 再生リストは1つのみ
* 追加、削除と行った編集が可能なこと

## GUI

* 再生位置をスライダーで移動できる
* 再生時間を表示
* 音量をスライダーで調整できる (0～200%)
* リバーブの強さをスライダーで調整できる (0% = 原音のみ ～ 100% = 響きのみ)
* 再生速度をスライダーで調整できる (0.5～2.0倍、音程は変えない)
* 音量・リバーブ・再生速度の設定は保存され、次回起動時に復元される
* リバーブ・速度の調整欄はアコーディオン形式で開閉できる (開閉状態は保存される)
* 再生中の音の周波数分布をビジュアライザー (棒グラフ) で表示する
* ボタンまたは V キーで表示の ON/OFF を切り替えられる (状態は保存される)
