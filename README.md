# Audio Player

ブラウザ上でローカル動作する音楽ファイル再生ツールです。サーバー不要で、`index.html` をブラウザで開くだけで使えます。

## 使い方

1. [AudioPlayer](https://hobione2k.github.io/AudioPlayer/)または`index.html` をブラウザ (Chrome / Edge / Firefox など) で開く
2. オーディオファイル (wav / mp3 / ogg / flac / m4a) を再生リスト領域にドラッグ＆ドロップ、または「ファイルを追加」ボタンで追加
3. 曲をクリックすると再生

## 機能

- 再生 / 一時停止 / 停止 / 前の曲 / 次の曲 (曲の終了時は次の曲を自動再生)
- 再生位置スライダーによるシーク、再生時間・曲の長さの表示
- 音量スライダー (0～200%、100%超は Web Audio API で増幅)
- 再生リストの追加・削除・全削除、ドラッグによる並べ替え
- テーマ切替 (トグルボタンでライト / ダークを切り替え、選択はブラウザに保存)
- ショートカットキーによる操作 (一覧は画面下部の「ショートカットキー」を参照)

## ファイル構成

- `index.html` … 画面構成
- `css/style.css` … 見た目
- `js/app.js` … 再生・再生リストの処理
- `js/theme.js` … テーマ切替の処理
- `docs/spec.md` … 仕様
